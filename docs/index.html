How it works

No hooks required. No config. No keys.

Your agents already write every message and tool call to disk. whatsmyagentdoing just reads along.

Tail the logs

Session logs under ~/.claude, ~/.codex, ~/.gemini and friends are read incrementally, never written.

Turn events into states

The latest event becomes Thinking, Running, Waiting or Done. Large logs read only their head and tail.

Stream to your browser

A tiny local server pushes snapshots over Server-Sent Events to the page. That's the whole stack.

🔒

Nothing leaves your machine. The server binds to 127.0.0.1 and rejects requests not addressed to localhost. The only network call is an optional version check, which you can turn off with WMAD_NO_UPDATE_CHECK=1.

FAQ

Questions

Does it slow my agents down or change anything?

No. It only reads log files. The optional approval hook writes one tiny marker file per permission prompt into ~/.whatsmyagentdoing and nothing else.

Why does Claude Code show “Running” while it waits for my approval?

Claude Code doesn't log permission prompts. Run node bin/cli.js --install-hook once to add an optional Notification hook, and they'll show as “Waiting for you”. --uninstall-hook removes it.

How do I update?

The page tells you when a new version is out. Click Update, run /myoffice update, or git pull in the skill folder.

Can I share my screen with it open?

Yes. Start it with --private to hide prompts, replies and titles and show status only.

My agent isn't listed. Can it be supported?

If it writes session logs to disk, probably. Open an issue with the log location and a short sample with the content removed.
