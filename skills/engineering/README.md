# Active engineering skills

- [to-spec](./to-spec/SKILL.md): turn the conversation into a GitHub issue spec.
- [to-tickets](./to-tickets/SKILL.md): split the spec into dependency-aware tickets.
- [implement](./implement/SKILL.md): build tickets one at a time with `tdd`.
- [implement-spec](./implement-spec/SKILL.md): build a whole spec in parallel.
- [code-review](./code-review/SKILL.md): review standards and spec compliance.
- [pr](./pr/SKILL.md): prepare the pull-request body.
- [retro](./retro/SKILL.md): improve the coding-agent environment.

Supporting `tdd` is kept in this folder because the implementation skills use
it directly.
