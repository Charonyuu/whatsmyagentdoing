# OMP (oh-my-pi)

Интеграция проверена с локальным OMP `18.12.6`. Она читает файлы сессий;
не изменяет журналы, не подключается к моделям и не запускает OMP.

## Каталоги

- Основной: `~/.omp/agent/sessions/<project>/*.jsonl`.
- `PI_CODING_AGENT_DIR` задаёт каталог агента; к нему добавляется `sessions`.
- Именованные профили обнаруживаются в `~/.omp/profiles/<name>/agent/sessions`.
  Учитываются `OMP_PROFILE` и совместимая `PI_PROFILE`; `OMP_PROFILE` имеет приоритет.
  Профиль передаётся в Resume, чтобы сохранить выбор настроек и авторизации.
- На Linux/macOS учитывается существующий `$XDG_DATA_HOME/omp/sessions`,
  для профиля — `$XDG_DATA_HOME/omp/profiles/<name>/sessions`.
  Профиль, существующий только в XDG и отсутствующий в `~/.omp/profiles`, нужно
  выбрать через `OMP_PROFILE` либо указать его хранилище явно.
- `WMAD_OMP_SESSIONS_DIR` или `--omp-dir <path>` заменяет автоматический список
  каталогов OMP. Это именно корень `sessions`, либо отдельный каталог,
  используемый в `omp --session-dir`. Флаг имеет приоритет над переменной.
  Для явно заданного каталога профиль берётся из `OMP_PROFILE`/`PI_PROFILE`.

Пример PowerShell:

```powershell
node 'C:\путь к myoffice\bin\cli.js' --omp-dir 'D:\OMP sessions' --no-open
```

После изменения переменных или параметров нужно перезапустить сервер.
Сервер не может узнать переменные, заданные только в другом терминале OMP.
Настройки удалённых Redis/SQL-хранилищ не читаются: нужен локальный JSONL.

## Обнаружение и чтение

Раз в 5 секунд проверяются каталоги и время изменения файлов, включая старые
проекты и сессии, возобновлённые спустя месяцы. По умолчанию показывается
активность за последние 24 часа (`--hours` меняет окно). Известные файлы
проверяются раз в секунду. Закрытие окна OMP без записи события нельзя
достоверно обнаружить по журналу; действуют обычные таймауты интерфейса.

Читаются только JSONL непосредственно в корне или в одном уровне каталогов
проектов. Соседние каталоги артефактов `<session-file-stem>/`, включая вложенные
subagent и `__advisor*.jsonl`, не обходятся. OMP subagent/advisor в этой версии
отдельными персонажами не отображаются. `parentSession` сохраняет происхождение
чата и не означает работающий subagent.

Настоящий ID и cwd берутся из записи `type: "session"`, а не из имени файла.
Произвольный JSONL без заголовка не отображается. Поддерживаются заголовок после
начального `type: "title"`, `title_change`, `model_change` и сообщения с точными
ролями `user`, `assistant`, `toolResult`. Служебные модели (`smol`, `tiny` и т. п.)
не подменяют основную модель при `model_change`; ответ показывает фактически
использованную модель. Содержимое thinking-блоков не показывается.

Большой журнал первоначально читается целиком порциями по 128 КиБ, чтобы не
потерять модель, последний запрос или незавершённый вызов в середине файла.
В памяти остаются краткие превью, незакрытые инструменты и незаконченная строка,
а не весь журнал. Последующие дополнения читаются с сохранённой позиции.
UTF-8 и незавершённая последняя строка сохраняются между опросами. Усечение,
замена файла и изменение без роста размера вызывают повторное чтение. Текущее
название в начальном слоте имеет приоритет над историческими записями.

## Состояния и ограничения

- Запрос пользователя → `thinking`.
- `toolCall` в assistant content и `custom/tool_execution_start` → `tool`.
- Незавершённый вызов `ask` → `waiting`; результат `ask` снимает ожидание.
- `toolResult` закрывает только свой `toolCallId`. Другие незавершённые вызовы
  продолжают отображаться; после последнего результата → `thinking`.
- Ответ со `stopReason: "stop"` или `"length"` → `done`, если инструментов не осталось.
  `length` означает остановку по лимиту, а не гарантию полноты ответа.
- `stopReason: "error"` → `error`, `"aborted"` → `interrupted`.
  Ошибка инструмента показывается до продолжения обработки; ошибка одного
  вызова не скрывает другие работающие инструменты.
- `custom/session_exit`: fatal → `error`; сигнал, ненормальное завершение
  или выход с незавершёнными инструментами → `interrupted`.

OMP сохраняет законченные сообщения, а не каждый фрагмент потокового ответа.
Поэтому точный момент начала генерации, ожидание API, разрешение на инструмент
и ожидание пользователя, если вызов `ask` ещё не записан, неразличимы.
События approval не выдумываются; вопросительный знак в ответе не означает
ожидание. Сторонние расширения с собственными форматами событий не распознаются.
Показаны последние сохранённые события файла; полное восстановление контекста
дерева веток и расширений OMP не выполняется.

## Resume и интерфейс

OMP есть в фильтре, легенде, карточках, 2D/3D и pop-out. Используется нейтральная
монограмма OMP из `assets/agents/omp.svg`, а не официальный логотип.

Сервер формирует команду по своей платформе:

```powershell
omp --profile 'default' --cwd 'C:\проект с пробелом\O''Brien' --session-dir 'C:\сеансы\project' --resume 'настоящий-id'
```

В Windows команда предназначена для PowerShell 5.1/7. Одинарные кавычки
удваиваются; `$()`, обратные кавычки и двойные кавычки внутри строк остаются
буквальными. В POSIX-оболочках используется соответствующее экранирование.
Если браузер открыт с другой платформы, выбирайте оболочку платформы сервера.
`--session-dir` позволяет находить сессию в нестандартном хранилище, а `--cwd`
не требует отдельной команды перехода в каталог. Resume не запускается
автоматически и может потребовать освобождения сессии текущим процессом OMP.

## Проверки

`npm run test:watcher` запускает изолированные проверки OMP и прежнего watcher.
`npm run test:ui` проверяет четыре провайдера, изображения, фильтры, копирование
Resume, 2D/3D, pop-out и узкие экраны на искусственных сессиях. Для UI нужны
зависимости разработки и установленный Google Chrome.

Формат сверялся с публичными исходниками версии 18.12.6:
[описание сессий](https://github.com/can1357/oh-my-pi/blob/v18.12.6/docs/session.md),
[пути](https://github.com/can1357/oh-my-pi/blob/v18.12.6/packages/utils/src/dirs.ts),
[типы записей](https://github.com/can1357/oh-my-pi/blob/v18.12.6/packages/coding-agent/src/session/session-entries.ts),
[вложенные сессии](https://github.com/can1357/oh-my-pi/blob/v18.12.6/packages/coding-agent/src/session/sub-sessions.ts).
